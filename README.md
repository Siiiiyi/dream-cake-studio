# Dream Cake Studio

一间奶油色的 3D 蛋糕创作室，使用 React、Vite、Three.js 和 React Three Fiber 制作。所有蛋糕、水果、奶油花与陶瓷蛋糕架都是程序化模型，没有付费模型或模型下载依赖。

## 如何打开

依赖已经安装。打开本文件所在的项目文件夹，在终端输入：

```sh
npm run dev
```

在浏览器打开终端显示的地址，通常是 http://localhost:5173 。如果这个端口正在使用，Vite 会自动选择下一个端口，请以终端显示的地址为准。保持终端运行，关闭页面不会自动关闭服务；在终端按 Ctrl+C 可以停止服务。

在一台新电脑上，需要先安装 Node.js 20.19+ 或 22.12+，然后执行一次：

```sh
npm install
npm run dev
```

不能直接双击 index.html 运行，项目需要由 Vite 启动。

## 怎么制作蛋糕

1. 初次打开时会有一份草莓奶油灵感初稿，可以直接修改，也可以点击 Reset 清空装饰。
2. 在「蛋糕底」选择香草、巧克力或抹茶。
3. 在「奶油」选择原味、草莓或巧克力，光标会变成带奶油的抹刀，并显示「抹奶油中」。按住蛋糕表面拖动，奶油会沿轨迹铺开，可以从顶面越过圆边抹到侧面。慢速、转弯、收笔会留下较厚的奶油，重复笔触会柔和叠加。抹刀持续补充奶油，长笔触的用量有变化，但不会耗尽；暂停、松开后可以直接继续，不必重新选择。按 Esc、切换工具或步骤、完成作品才退出。换口味只影响之后的笔触。初始夹心和底部裱花保持原味。
4. 在「水果」或「装饰」点击一种材料，然后移到蛋糕顶部查看半透明预览。点击想放的位置才会落下，可以连续放置。绿色圈表示位置可用，红色表示太靠边或与其他材料重叠。
5. 直接按住已有水果或装饰拖到新位置，松开后固定。拖动时镜头会暂时锁住。选中后仍然可以调整大小、旋转或删除；也可以通过「已放置装饰」下拉菜单选中物件。原来的上下左右箭头已由直接拖动替代。
6. 手机/平板使用手指轻点放置，或按住预览、移动后松开放置；拖动已有水果时它会跟随手指。画面周围的空白处仍可以拖动旋转蛋糕；也可以取消材料选择，或按 Escape 退出当前工具。滚轮可以缩放，镜头仍设有距离和角度限制。
7. Reset 清空手工涂抹的奶油和顶部装饰，保留口味选择、夹心与底部固定裱花。旁边的撤销/重做可以恢复最近的修改，最多保留 60 个历史状态。一次完整涂抹或拖动只占用一次撤销。
8. 第四步点击 Finish 进入最终作品页，可以为作品命名，点击「保存作品 PNG」下载 1800 × 1800 图片，也可以返回继续修改。

为防止装饰互相穿透，放大后发生碰撞的操作会被拒绝；拖动时会停留在最后一个有效位置，并以红色圈提示碰撞。最多可添加 32 件装饰。底部固定的奶油裱花属于蛋糕造型，不在可删除装饰之内。抹奶油支持顶面、圆角和完整侧面，接近真实蛋糕底部才渐薄收边；不能在空气或托盘上涂抹。自由放置水果仍限于顶部。奶油总采样点上限为 3000，达到上限时会提示，可撤销或重置后继续。

当前版本将创作保存在页面运行期间的内存里，刷新或关闭页面会回到初始作品。请在离开前保存成 PNG。

## 文件怎么理解

| 文件 | 用通俗的话解释 | 适合修改什么 |
| --- | --- | --- |
| `src/App.jsx` | 页面的总导演：决定当前步骤、口味、装饰、按钮与完成页 | 页面文案、初始蛋糕、步骤、交互流程 |
| `src/styles.css` | 页面外观的设计稿：颜色、字体、间距与手机布局 | 主色调、文字大小、边框、按钮、布局 |
| `src/catalog.js` | 食材菜单：每种材料的名称、说明和颜色 | 食材名字、中英文标签、蛋糕与奶油颜色 |
| `src/CakeScene.jsx` | 3D 摄影棚：蛋糕、陶瓷架、灯光、镜头与阴影 | 蛋糕比例、层高、灯光亮度、初始角度 |
| `src/ToppingModel.jsx` | 小型造型工坊：水果、奶油花、巧克力、糖珠与蜡烛 | 水果造型、几何细节、装饰材质 |
| `src/fruitSurface.js` | 水果皮肤：生成多色顶点、不规则轮廓、草莓籽窝与果粉凹凸 | 水果配色、表面起伏与种子位置 |
| `src/Frosting.jsx` | 显示贴合表面的奶油层和可涂抹的表面 | 网格精度、奶油表面材质 |
| `src/frostingGeometry.js` | 生成顶面、圆角、侧沿及嵌入蛋糕的闭合底面 | 贴合几何体、边缘封闭、颜色融合 |
| `src/frosting.js` | 刮刀用量、速度与转弯行为、蛋糕曲面及水果支撑高度 | 刮刀宽度、奶油厚度、抹刀痕迹 |
| `src/SurfaceInteraction.jsx` | 鼠标和触摸的直接操作：射线检测、预览、涂抹、拖动与镜头锁定 | 指针手势与交互细节 |
| `src/surface.js` | 把屏幕位置准确转换到蛋糕表面的公共坐标工具 | 射线检测和表面交点 |
| `src/design.js` | 摆放规则：寻找空位，限制尺寸，避免碰撞 | 最大装饰数量、摆放密度与尺寸限制 |
| `src/export.js` | 作品摄影与排版：高分辨率截图、作品名和 PNG 下载 | 导出图片尺寸、背景颜色、图片上的文案 |
| `tests/design.test.js` | 自动检查摆放规则的小助手 | 验证装饰不会越界、重叠或接受无效尺寸 |
| `tests/frosting.test.js`、`tests/surface.test.js`、`tests/fruit.test.js` | 检查涂抹厚度、不同视角坐标和水果细节 | 交互与材质回归验证 |

## 常见修改

### 改页面颜色

在 `src/styles.css` 最上面的 `:root` 中修改：

```css
--paper: #faf7f2;  /* 奶油色背景 */
--ink: #594b40;    /* 文字 */
--green: #74836a;  /* 鼠尾草绿点缀 */
--caramel: #a78062; /* 焦糖色点缀 */
```

部分装饰细节有独立颜色，可以搜索相应的十六进制颜色继续微调。修改文件后，浏览器会自动更新。

### 改口味颜色或名字

在 `src/catalog.js` 中找到对应材料，修改 `name`（中文名）、`en`（英文名）、`color`（颜色）和 `note`（短文案）。例如，香草蛋糕的颜色是 `#dcb980`。水果的多色 3D 配色在 `src/fruitSurface.js` 顶部的 `palettes` 中，菜单颜色在 `catalog.js` 中。奶油笔触会记录开始涂抹时的颜色，因此已有作品不会因换口味而整体变色。

### 改一开始看到的蛋糕

在 `src/App.jsx` 中找到 `starterDesign()`。其中的数组决定初始装饰，`base` 和 `cream` 决定初始口味。如果希望从空白蛋糕开始，把装饰数组改成 `[]` 即可。

### 新增一种水果

需要同时修改 `catalog.js` 中的材料清单和 `ToppingModel.jsx` 中的立体造型。仅增加菜单名称不会自动生成新的 3D 模型。`radius` 是自动摆放时使用的占位半径，应该与实际模型大小相符。

### 改导出图片

在 `src/export.js` 中调整 `canvas.width`、`canvas.height` 与文字的坐标。3D 画面会单独高分辨率渲染，所以手机端也可以导出清晰图片。

## 构建与检查

```sh
npm test
npm run build
npm run preview
```

`npm test` 检查摆放规则、刮刀轨迹、长笔触与暂停恢复、速度与转弯堆积、厚度叠加上限、奶油闭合底面与侧面贴合、桌面和手机及旋转视角的坐标映射、水果色差、草莓圆润底部与连续收窄轮廓、宽萼片和蓝莓凹陷；`npm run build` 生成 `dist` 文件夹；`npm run preview` 在本地预览构建结果，一般地址为 http://localhost:4173 。

本项目按奶油涂抹、自由放置/拖动、水果材质三个阶段执行构建。交互验收步骤见 `TESTING.md`。手机尺寸的浏览器检查不等于所有真实触屏设备的兼容性测试。

## 运行说明

### GitHub Pages 发布

仓库名称预计为 `dream-cake-studio`。发布配置参考 [Vite 官方指南](https://vite.dev/guide/static-deploy.html#github-pages) 和 [GitHub Pages 工作流说明](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。

- 本地 `npm run dev`、`npm run build` 和 `npm run preview` 仍使用根路径，不改变原有本地预览方式。
- `.github/workflows/deploy.yml` 会在推送到 `main` 或手动运行时，安装锁定依赖、测试、构建并部署。只有这个工作流设置 `DEPLOY_TARGET=github-pages`，使资源路径变为 `/dream-cake-studio/`。
- 上传后，在仓库的 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。预计网址为 `https://Siiiiyi.github.io/dream-cake-studio/`，首次运行成功后以 Actions 输出的网址为准。
- 仓库名以后改变时，需要同步修改 `vite.config.js` 的发布路径。
- 不要手动上传 `node_modules` 或 `dist`。`.env`、凭据、测试截图及日志已排除；前端项目的 `VITE_` 变量会进入公开网页，不能存放密钥。
- 当前仅准备本地文件和 Git，不会自动创建远程仓库或执行推送。上传前请确认提交作者邮箱使用 GitHub 提供的 noreply 地址。
- 第三方依赖和字体说明见 `THIRD_PARTY_NOTICES.md`。未擅自为项目选择开源许可证。

- 3D 需要浏览器启用 WebGL/硬件加速，建议使用较新的 Chrome、Safari、Edge 或 Firefox。
- 字体从 Google Fonts 加载；无法联网时会使用系统字体，蛋糕和交互仍然可以运行。
- 这是前端创作工具，无账号、支付、后台服务器或外部 3D 资源请求。
- Three.js 的生产文件较大，构建时可能出现文件体积提醒，不影响运行。3D 模块已单独加载。

技术参考：[React Three Fiber Canvas](https://r3f.docs.pmnd.rs/api/canvas)、[Drei 镜头控制](https://drei.docs.pmnd.rs/controls/introduction)。
